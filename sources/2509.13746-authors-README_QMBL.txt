PYROCHLORE HEISENBERG, L=4, N=256: MEASUREMENT DATA AND PARAMETERS

MODEL AND STATE
H = J sum_<ij> S_i . S_j, spin 1/2, J=1 in the code.
N=4 L^3=256 sites; periodic boundary conditions in all three directions.
The sampler works in total Sz=0. Parameters are held fixed throughout.
This is a variational-state energy estimate, not an exact eigenvalue.

REPORTED VALUES (one-standard-error statistical uncertainties)
E/N = -0.4855840 +/- 0.0000029 J
E   = -124.30952 +/- 0.00074 J
V_H = <H^2>-<H>^2 = 4.894 +/- 0.022 J^2
V_H/N = 0.019116 +/- 0.000087 J^2
V_H/N^2 = Var(H/N) = (7.467 +/- 0.034) x 10^-5 J^2
Full precision and the individual error estimates are in pyro-result.dat.

SAMPLING AND UNCERTAINTY
One production run: 256 separately seeded chains, each with 1000 discarded
warmup sweeps followed by 32768 samples. Total samples: 8388608.
One sweep is 256 attempted antiparallel-bond exchanges, including rejected
moves. Sampling interval: one sweep. Base seed: 2026091901.
The full-chain means give SEM(E/N)=2.8891780023e-6 J. Blocks of 1024 samples
give 2.8674001889e-6 J. Blocks do not cross chain boundaries. Error estimates
at block sizes >=256 span 2.8397e-6 to 2.9161e-6 J/site.
Samples within chains must not be assumed independent just because they
are separated by one sweep. The quoted uncertainty uses the full-chain
estimate, supported by the blocking table.

VARIANCE DEFINITION
E_loc(sigma)=(H psi)(sigma)/psi(sigma), sampled with probability |psi|^2.
The estimate is mean(|E_loc|^2)-mean(Re E_loc)^2. Both (Re E_loc)^2 and
(Im E_loc)^2 are included. For numerical stability the source accumulates
the real part around the fixed reference -N/2; this is algebraically the
same estimator. The reported variance is the plug-in estimate. The small
jackknife bias correction is listed separately in pyro-blocking.dat.
The variance error comes from deleting whole blocks and recomputing the
combined first- and second-moment estimator. At block size 1024, its SEM
is 0.02217109077 J^2; deleting whole chains gives 0.02212960990 J^2.

SCOPE OF THE CHECKS
The chain and blocking outputs support the quoted statistical errors.
Only one production run is included; a second base seed and longer warmup
have not been tested in this dataset. Raw chronological local-energy
samples were not saved, so arbitrary reblocking and a full tail analysis
cannot be reconstructed from these files. The variance uncertainty is
more sensitive to high-second-moment chains: rank 169 contributes about
25.3% of the summed squared leave-one-chain-out deviations used in its
jackknife error. No chains were excluded. This is a sampling sensitivity
diagnostic, not evidence that rank 169 is erroneous. An additional run
would strengthen the assessment of the variance uncertainty.

PARAMETER FORMAT AND WAVEFUNCTION RECONSTRUCTION
ini contains 262144 lines with three columns: index, x(index), auxiliary.
The third column is ignored. Indexing below is 1-based, as in Fortran.
For i=1,...,512 and j=1,...,256, let k=(j-1)*512+i. Then

    mat(i,j) = x(k) + imaginary_unit*x(k+131072).

This is a 512 x 256 complex orbital matrix, not a directly tabulated
pair-amplitude matrix. For a spin configuration with 128 up-spin sites
u_1,...,u_128, form the 256 x 256 matrix

    A(2a-1,j) = mat(u_a,j),
    A(2a,j)   = mat(u_a+256,j),    a=1,...,128.

The sampled amplitude is psi(sigma) proportional to det A(sigma).
Exchanging the order of two up-spin sites swaps pairs of rows and does
not change the determinant sign. The sampling weight is |det A|^2.
The site index is

    site(i,j,k,l)=((i-1)*L^2+(j-1)*L+(k-1))*4+l,

with i,j,k=1,...,L and l=1,...,4. The neighbor() subroutine specifies the
periodic bond connectivity; it contains 768 distinct undirected bonds.
The local_energy() subroutine sums every physical bond once.

FILES
ini                 Exact input parameter file supplied with this run.
pyro-ph.for         Standalone Fortran measurement source; reads ini.
pyro-result.dat     Full-precision summary and run settings.
pyro-blocking.dat   Block sizes, energy SEM and variance jackknife SEM.
pyro-chains.dat     Per-chain means, variance estimates and diagnostics.
README_QMBL.txt     This document.
SHA256SUMS.txt      SHA-256 checksums of the files above.

The three original output files are unchanged. Their generic source
status line 'statistical_validation = pending' is not overwritten; the
scope and limits of the subsequent numerical checks are explained here.
No original per-chain sample trace is included because none was saved.

BUILD AND RUN
Place pyro-ph.for and ini in the same directory. No configuration file.
Use a clean build directory or matching compiler module files.
GNU Fortran with MPI and LAPACK/BLAS, for example:
    mpifort -O2 -ffixed-form -ffixed-line-length-72 pyro-ph.for \
        -o pyro-ph.x -llapack -lblas
Intel MPI / Intel Fortran / MKL, for example:
    mpiifort -O3 -fixed -extend-source 72 -traceback \
        -qmkl=sequential pyro-ph.for -o pyro-ph.x
Set OMP_NUM_THREADS=1, MKL_NUM_THREADS=1, OPENBLAS_NUM_THREADS=1.
Then launch with your scheduler/MPI environment, for example:
    mpirun -np 256 ./pyro-ph.x
The program overwrites pyro-result.dat, pyro-blocking.dat and
pyro-chains.dat, so use a separate directory for a new measurement.
Sampling settings and base_seed are near the top of pyro-ph.for.
Change base_seed and recompile for a new random initialization.
RANDOM_NUMBER is compiler-dependent, so bitwise identical samples are
not promised across different compilers or runtime implementations.
